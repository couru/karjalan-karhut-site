# Правила проекта

## Репозиторий и публикация

- Единственный удалённый репозиторий проекта — GitHub `origin`: `https://github.com/couru/karjalan-karhut-site.git`.
- Все изменения проекта нужно фиксировать в Git и отправлять только в GitHub `origin`.
- Не использовать OpenAI Sites, `chatgpt.site`, внутренние репозитории или другие хостинги для сохранения и публикации изменений.
- Публичная версия сайта размещается только через GitHub Pages из GitHub-репозитория проекта.
- Перед отправкой проверять текущую ветку и не отправлять изменения напрямую в `main`, если пользователь явно этого не попросил.
