# Karjalan Karhut

Независимый концепт-пример ребрендинга хоккейного бренда Karjalan Karhut.
Проект не связан с действующими хоккейными клубами и не заявляет прав на это
название. Работает без Next.js, React, серверного рендеринга и базы данных.

Концепция и дизайн проекта: Ян Ковру. В визуальных материалах использованы
инструменты генеративного ИИ.

## Структура

- `index.html` — содержимое страницы;
- `styles.css` — оформление и адаптивные правила;
- `script.js` — доступное мобильное меню;
- `public/` — изображения и клубная символика;
- `dist/` — готовая к публикации сборка.

## Локальный запуск

```bash
npm install
npm run dev
```

## Проверка и сборка

```bash
npm test
```

Команда проверяет статическую структуру и создаёт каталог `dist`. Для
публикации на статическом хостинге нужно загрузить содержимое `dist` в корень
сайта.

## Адаптивность

Интерфейс рассчитан на телефоны от 320 px, планшеты и широкие десктопные
экраны. На устройствах до 900 px основная навигация заменяется мобильным меню.
Клубные нашивки остаются неподвижными при наведении и касании.

## GitHub Pages

Сайт автоматически собирается и публикуется из ветки `main` с помощью GitHub Actions:

https://couru.github.io/karjalan-karhut-site/

Пути к стилям, скриптам и изображениям относительные, поэтому сайт работает в каталоге
репозитория GitHub Pages. Текущее размещение и файл `.openai/hosting.json` сохранены.
