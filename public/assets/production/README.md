# Karjalan Karhut — макет вышивки на кепку

Комплект предназначен для нанесения эмблемы на чёрную бейсболку.

## Файлы

- `karjalan-karhut-cap-emblem-graphite-karelia.eps` — основной производственный макет; все элементы представлены кривыми, шрифтов и встроенного растра нет.
- `karjalan-karhut-cap-emblem-graphite-karelia.svg` — редактируемая векторная копия.
- `karjalan-karhut-cap-emblem-graphite-karelia-vector-preview.png` — растровое превью макета на чёрном фоне.

## Параметры

- рабочее поле: 100 × 100 мм, макет допускает масштабирование;
- палитра: три графитовых оттенка, приглушённое золото для надписи, тёмный хвойный зелёный, приглушённый красный и приглушённый синий;
- надпись `KARJALAN KARHUT` выполняется приглушённой золотой нитью (`#9B7D4A` в макете);
- чёрный фон является тканью кепки и не должен зашиваться;
- перед производством макет необходимо оцифровать в машинный формат вышивки с учётом оборудования и выбранных ниток.
